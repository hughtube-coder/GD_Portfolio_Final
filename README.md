# Hugh Daniel J. Raymundo: Portfolio

Static site (HTML, CSS, JS). No build step. All files live at the top level of the repo.

## Publish on GitHub Pages
Repo Settings > Pages > Deploy from a branch > `main` / root. Site: https://hughtube-coder.github.io/GD_Portfolio/

## Things you can swap
- `profile.jpg`: your photo on the About page (keep the name; a 4:5 portrait works best).
- `tile-01.jpg` ... `tile-10.jpg`: the "More about me" gallery images.
- `promo.mp4` and `poster.jpg`: the promo video and its cover image.

## Hidden features
Click the photo on the About page to open the console: dark mode, lava and cursor-trail switches, a bug-invaders game, a terminal, and a typed `whoami.py`.

## Loading screen
Shown once per browser session. To replay it: open the console on the About page and type `intro`, or open the site in a new private window.

## Works
Activities are grouped by term (Prelim, Midterm) in `works.html`. Add a new activity by copying an `<article class="work">` block into the right term.
